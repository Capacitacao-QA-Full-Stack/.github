# Capacitação QA Full Stack

Uma plataforma para aprender as principais ferramentas usadas no mercado de trabalho. Mais do que um ambiente de cursos, uma comunidade para estudar, realizar desafios de teste e se desenvolver.

Conheça [capacitacao_qa_full_stack_lp/index.html](../capacitacao_qa_full_stack_lp/index.html). 

Os cursos ficam em trilhas, como na área de membros. Abaixo, o que já está na plataforma e o que entra em breve.
